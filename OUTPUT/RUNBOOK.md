Generated by the `level3-web-design` skill. Paste the prompts into Claude Code in

## Prerequisites (one-time)
- You are on `redesign/level3` (already created off `master`).
- Node.js 22+
- `npm install -g @vizzly-testing/cli && vizzly init`
- Add Vitest for the static + component test layers (Prompt 3 will do this).

## Project summary
- **Product:** WrenchIt - lean KL software studio, AI-powered apps + automation for APAC founders/SMEs
- **Audience:** founders and SMEs who value working software over roadmaps
- **Scope:** single-page homepage (six sections) + `/batch`, optional `/faq`, branded 404, contact-form states
- **Accent (committed):** ink-blue / navy `oklch(0.42 0.14 265)` - purple deleted
- **Display / Text / Mono:** Fraunces / Schibsted Grotesk / JetBrains Mono
- **Radius:** pill buttons + 0-radius surfaces
- **Testing depth:** (d) full Vizzly TDD
- **Branch:** `redesign/level3` -> merge to `master` when green

> The non-negotiable core: OKLCH only, one navy accent used at most once per
> section, asymmetric layout with real negative space, no purple, no stats row /
> ghost CTA / glow / shadow ladder, and every anti-pattern is a failing test. If
> the homepage could be reused for another studio by swapping the name, it has
> failed.
